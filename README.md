# GeneReviews Mirror

This is a mirror of the NCBI GeneReviews resource, designed for offline access and reference.

## Features

- Complete mirror of GeneReviews content
- Mobile-responsive design for better viewing on all devices
- Search functionality that works offline
- Back-to-top buttons for easier navigation

## Usage

Visit the [index.html](./index.html) page to start browsing the mirrored content.
